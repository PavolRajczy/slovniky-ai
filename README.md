## Docker (mock UI + agentic backend)

Celý návod **[DOCKER.md](DOCKER.md)**.

Stručne — príkazy spúšťaj v **koreni repozitára** (tam, kde je `docker-compose.yml`), s `OPENAI_API_KEY` v `.env`:

```bash
docker compose up --build
```

- UI: http://localhost:8080
- API docs: http://localhost:8000/api/docs
